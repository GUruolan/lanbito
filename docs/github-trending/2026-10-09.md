### 1. mattpocock/skills

**项目简介**：面向真实工程开发的可组合技能集合，覆盖需求澄清、规格实施、测试与评审。

**关注价值**：适合将单个技能加入已有流程；插件与复制的技能文件属于不同维护方式，重复安装会增加理解成本。

### 2. Panniantong/Agent-Reach

**项目简介**：为 Agent 选择、检查和路由互联网读取工具，覆盖网页、视频字幕及多个内容平台。

**关注价值**：应区分路由器和实际执行读取的上游工具；“零 API 费用”不表示所有平台都无需配置或登录。

### 3. heygen-com/hyperframes

**项目简介**：以 HTML 编写视频内容，再进行预览、编辑和渲染的框架。

**关注价值**：本期摘要关注按渲染块提取帧和字幕处理；长视频要检查规划耗时、成片画面和音画同步。

### 4. thedotmack/claude-mem

**项目简介**：记录 Agent 会话活动、通过 AI 压缩并在后续会话注入相关内容的持续记忆工具。

**关注价值**：适合研究分层检索，先取索引再取详情；需确认实际存储和处理路径，而不能仅凭“记忆”标签判断本地性。

### 5. mvschwarz/openrig

**项目简介**：将 Claude Code、Codex、Pi 等终端 Agent 组织成具有角色、共享上下文与任务归属的持续团队。

**关注价值**：关注任务队列、恢复和交接；后台团队的生命周期与终端窗口生命周期需要分开理解。

## 📈 趋势判断

跨会话记忆与持续团队说明任务上下文开始跨越一次对话。工程上更值得研究的是任务归属、记忆检索和恢复，而不只是增加 Agent 角色。
