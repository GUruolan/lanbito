## 📊 回填 Top 5

### 1. PrimeIntellect-ai/prime-agent ⭐ 21,100

- 🔗 https://github.com/PrimeIntellect-ai/prime-agent
- 语言：TypeScript
- 本周新增：约 2,579 stars

**项目简介**

面向编码工作流和长时间自治任务的自改进 RLM Agent。它关注的不是一次性问答，而是让 Agent 在长期任务中保留工作模式、拆分子任务并持续推进。

**为何值得关注**

长任务是编码 Agent 的核心难点：上下文会耗尽，任务会分叉，经验很难沉淀。`prime-agent` 的热度说明开发者开始重视 Agent 的持续执行能力，而不只是单轮代码生成。

### 3. firecrawl/anydoc ⭐ 21,900

- 🔗 https://github.com/firecrawl/anydoc
- 语言：Rust
- 本周新增：约 1,197 stars

**项目简介**

Rust 编写的文档处理工具，可将 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF 等格式转换为干净 Markdown，并提供 Node.js 与 Python bindings。

**为何值得关注**

Markdown 仍是 Agent、RAG 和知识库最容易处理的中间格式。`anydoc` 的意义在于把 Office 和 PDF 等复杂文件转换成更适合 LLM 消费的结构化文本。

## 📈 趋势判断

### 趋势一：Agent 开始补齐长期任务能力

`prime-agent` 和 `OmniRoute` 都指向同一个问题：Agent 不只是一次性生成代码，而是要在多模型、多工具、长任务中稳定工作。

### 趋势二：文档清洗成为 AI 基础设施

`anydoc` 的热度说明“把复杂文件变成 Markdown”仍是 RAG、知识库和 Agent 工作流里的高频刚需。

### 趋势三：Skill 生态继续细分

从通用工程 Skill 到安全 Skill，开发者正在把专业经验拆成可复用模块，让 Agent 按更稳定的方式执行任务。
