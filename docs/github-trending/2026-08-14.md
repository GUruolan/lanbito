## 📊 回填 Top 5

### 1. cathrynlavery/diagram-design ⭐ 19,271

- 🔗 https://github.com/cathrynlavery/diagram-design
- 语言：HTML
- 本周新增：14,735 stars

**项目简介**

面向 Claude Code、Codex 和 Pi 的图表 Skill，输出自包含 HTML + SVG，支持架构图、流程图、金字塔图等技术表达场景。

**为何值得关注**

AI 生成的图表经常停留在“能看但不好用”的阶段。`diagram-design` 把排版、颜色、密度和重点表达写成规则，让 Agent 输出更接近可发布材料。

### 2. PrimeIntellect-ai/prime-agent ⭐ 16,472

- 🔗 https://github.com/PrimeIntellect-ai/prime-agent
- 语言：TypeScript
- 本周新增：8,488 stars

**项目简介**

Prime Intellect 的开源编码与研究 Agent，基于 recursive language model 和 durable harness，面向长时间运行的开发任务。

**为何值得关注**

它尝试把上下文变成变量、把子 Agent 变成函数调用，并用持久 harness 保存技能、记忆和子 Agent 配置。适合迁移、重构和长期研究任务。

### 3. semantica-agi/semantica ⭐ 8,107

- 🔗 https://github.com/semantica-agi/semantica
- 语言：Python
- 本周新增：5,339 stars

**项目简介**

面向企业 AI Agent 的图原生上下文与知识基础设施，把企业数据转为 context graph 和 knowledge graph，并为结论保留 provenance。

企业不是只要答案，还要知道答案为什么成立。`semantica` 的价值在于把“可解释、可追溯、可审计”放在 Agent 语境里处理。

## 📈 趋势判断

### 趋势一：技术表达也需要 Skill 化

`diagram-design` 的增长说明文档、方案和图表不是边缘需求。Agent 生成内容如果要进入正式交付，就必须符合视觉与表达标准。

### 趋势二：Agent 记忆从个人上下文走向团队资产

`TencentDB-Agent-Memory` 和 `semantica` 都在处理“知识如何长期存在、如何被解释、如何被多人复用”的问题。

### 趋势三：工程流程正在被产品化

`agent-skills` 继续上榜，说明开发者需要的不只是代码生成，而是稳定、可执行、可复查的工程流程。
