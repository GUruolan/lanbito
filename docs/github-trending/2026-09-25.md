### 1. cloudflare/security-audit-skill

**项目简介**：用于多阶段安全审计的编码 Agent 技能，将侦察、覆盖检查、独立验证和结构化报告组织成流程。

**关注价值**：适合研究发现与验证的分离。历史摘要指出该周未发现默认分支新增提交，因此上榜不应被写成新版本发布。

### 2. alibaba/open-code-review

**项目简介**：使用确定性规则和 LLM Agent 进行代码评审，定位到行级问题。

**关注价值**：本期摘要关注带引号路径、文件重命名和非 ASCII 文件名等边界；评审流水线修复与模型缺陷识别能力是不同问题。

### 3. stablyai/orca

**项目简介**：整合本地与远程编码 Agent、工作区和会话管理的开发环境。

**关注价值**：关注启动、断线、恢复和停止的完整生命周期；工作区隔离仍需考虑端口、分支与外部服务共享。

### 4. affaan-m/ECC

**项目简介**：跨编码 Agent 的技能、记忆、安全与工作流配置系统。

**关注价值**：本期摘要强调失败步骤与下游证据、命令检查和文件服务范围等执行边界；需区分默认分支与已发布版本。

### 5. Tencent/WeKnora

**项目简介**：将原始文档组织为可查询 RAG、自主推理 Agent 和持续维护 Wiki 的知识平台。

**关注价值**：适合研究知识检索如何连接多步骤任务；先评估检索质量，再评估工具调用行为。

## 📈 趋势判断

安全与评审工具更需要可复查的证据链。推荐比较问题定位、验证依据和报告格式，避免仅按工具输出的发现数量判断效果。
