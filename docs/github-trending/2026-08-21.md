输入主题或关键词后，自动生成脚本、寻找素材、合成配音、字幕和背景音乐，并渲染成竖屏短视频的内容生产流水线。

### 3. volcengine/OpenViking ⭐ 31,659

- 🔗 https://github.com/volcengine/OpenViking
- 语言：Python
- 本周新增：3,033 stars

**项目简介**

面向 AI Agent 的上下文数据库，把 memory、resources 和 skills 挂载到 `viking://` 虚拟文件系统下，让 Agent 像浏览目录一样浏览上下文。

**为何值得关注**

传统向量检索很难解释“为什么检到了这个结果”。`OpenViking` 把上下文组织成可浏览路径，并保留 retrieval trajectory，让 Agent 记忆更可调试。

- 语言：Python
- 本周新增：2,985 stars

**项目简介**
