### 1. morluto/rea：让 Agent 进入逆向分析流程

**项目简介**：REA（Reverse Engineer Anything）通过统一 MCP 接口连接软件分析工具，面向原生二进制、JavaScript/Electron 应用、.NET 程序集和网站等对象。

**核心特性**

- 结合应用行为、静态代码与二进制分析；分析在本地执行。
- 原生分析可使用已有的 Hopper、Ghidra 或 IDA，静态 JavaScript 分析不要求原生分析引擎。
- README 强调输出结论的证据和局限，也提供终端使用方式。

**关注价值**：适合研究 Agent 如何组织专业工具和分析证据。统一入口的价值在于降低工具切换成本，具体分析质量仍取决于目标、工具和验证过程。

### 2. boykopovar/AnyPS5：可执行文件移植路线

**项目简介**：面向 PS5 可执行文件到 Linux、Windows 的自动移植工具。README 描述的路线是重链接为目标系统原生格式，并实现可动态链接的系统 PRX 库。

**核心特性**

- 重链接器与系统库实现共同构成兼容路径，项目自述不使用模拟或独立运行时进程。
- 着色器重编译器生成 SPIR-V，可在启用相应构建选项时使用 SPIRV-Tools 验证。
- 按游戏跟踪启动阶段、阻塞项和 GPU 覆盖情况。

**关注价值**：适合了解二进制格式、动态链接、系统 API 与图形管线的边界。README 明确说明库进度的分母是项目已知函数，不是全部 PS5 系统函数；不能把进度百分比直接解释成整体游戏兼容率。

### 3. mattpocock/skills：可组合的工程经验

**项目简介**：Matt Pocock 日常使用的 Agent 技能集合，强调小型、易修改、可组合的工程流程。

**核心特性**

- 面向真实应用开发中的需求沟通与工程执行问题。
- 支持通过插件或 skills.sh 等方式接入不同 Agent。
- README 区分插件自动更新与复制到项目后手动维护的文件。

**关注价值**：适合观察如何把个人工程经验转成可复用指令。相比直接收集大量技能，更值得阅读其适用条件、任务输入和完成标准。

### 4. heygen-com/hyperframes：用 Web 技术生成视频

**项目简介**：将 HTML、CSS、媒体资源和可定位时间的动画渲染为确定性的 MP4 视频的开源框架。

**核心特性**

- 提供本地 CLI，也能通过技能接入 AI 编码 Agent。
- 工作流覆盖规划、编写 HTML、动画编排、检查、预览和渲染。
- 区分核心技能与完整技能集合，按任务加载对应能力。

**关注价值**：前端开发者可以复用布局、样式和动画经验参与视频生产。值得研究的是内容描述、时间轴和最终视频输出之间如何保持一致。

### 5. cathrynlavery/diagram-design：可独立交付的图表

**项目简介**：为 Agent 提供图表设计技能，输出自包含的 HTML + SVG 文件，支持品牌颜色和字体等设计约束。

**核心特性**

- 覆盖架构图、象限图、时序表达等多种图表形式。
- 输出可直接在浏览器打开的单文件产物。
- README 提供品牌适配、导入和导出相关入口。

**关注价值**：适合技术说明、方案展示和可共享图表。周榜简介写有 44 类图表，当前 README 写有 45 类；两处内容存在更新差异，本文不将数量作为稳定能力指标。

### 6. NationalSecurityAgency/ghidra：成熟的二进制分析底座

**项目简介**：NSA 研究部门维护的软件逆向工程框架，支持 Windows、macOS 和 Linux。

**核心特性**

- 提供反汇编、汇编、反编译、图形分析和脚本能力。
- 支持多种处理器指令集与可执行文件格式。
- 可交互使用，也可自动化运行，并通过 Java/Python 脚本或扩展增强能力。

**关注价值**：与 `rea` 一起阅读，可以区分专业分析引擎负责的能力和 Agent 负责的任务组织。工具被 Agent 接入并不改变底层分析结果仍需核验的要求。

### 7. ranxianglei/billion-context：长会话的上下文管理

**项目简介**：位于 Agent 与模型 API 之间的上下文压缩工具，通过代理处理 Anthropic/OpenAI 格式的请求与流式响应。

**核心特性**

- 提供 `compress`、`decompress`、`search_context` 和 `acp_status` 等上下文管理工具。
- README 强调增量压缩、按需恢复和前缀缓存友好。

**关注价值**：适合研究长任务中的记忆组织与成本管理。项目所述“5 倍 token 节省”“数月单会话”等属于作者声明；本期没有独立复测，也不能将累计处理量理解为模型原生上下文窗口大小。

## 📈 深度趋势分析

### 趋势一：Agent 接口正在进入专业软件

`rea` 与 `text-to-cad` 的共同点是将专业能力包装成 Agent 可调用的工作流。由此推断，工具竞争会逐渐涉及证据可追踪、结果可检查和产物可交付，而不只是自然语言入口。

### 趋势二：Skill 从通用提示转向领域约束

工程流程、SwiftUI、图表设计分别对应不同的错误类型和完成标准。本次榜单显示多种专业技能受到关注，但 star 数据不能证明某种技能已经提升了生产效率；真正效果仍需任务级比较。

### 趋势三：Web 技术成为内容产物的共同表达

`hyperframes` 使用 HTML/CSS 生成视频，`diagram-design` 使用 HTML/SVG 生成图表。两者说明浏览器技术可用于描述可编辑、可预览、可版本管理的内容，前端能力的应用范围正在延伸。

### 趋势四：长任务需要显式管理上下文

`billion-context` 把压缩、恢复、检索暴露为工具。这个方向提醒我们：长会话能力不仅取决于窗口大小，还取决于哪些信息被保存、何时恢复，以及任务能否在压缩后继续准确执行。
