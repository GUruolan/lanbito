## 📊 回填 Top 5

### 1. freestylefly/awesome-gpt-image-2 ⭐ 24,238

- 🔗 https://github.com/freestylefly/awesome-gpt-image-2
- 语言：JavaScript
- 本周新增：12,877 stars

**项目简介**

GPT-Image-2 prompt 引擎和模板库，包含 530+ 逆向案例和 20+ 可作为 Skill 加载到编码 Agent 的模板。

**为何值得关注**

图像生成从“写 prompt”走向“Prompt as Code”。把 prompt 案例、模板和技能组织起来，可以降低重复试错成本，也便于版本化管理。

### 2. tt-a1i/archify ⭐ 27,415

- 🔗 https://github.com/tt-a1i/archify
- 语言：JavaScript
- 本周新增：11,099 stars

**项目简介**

面向 Cursor、Claude Code、Codex CLI 和 OpenCode 的架构图 Skill。Agent 输出 typed JSON，本地渲染器再确定性编译成 HTML/SVG 架构图、工作流图、时序图和数据流图。

**为何值得关注**

它把模型直接画图改为“模型生成结构化中间表示，渲染器负责确定性输出”。这比直接生成 Mermaid 或 SVG 更容易校验，也更适合代码评审场景。

---

### 3. openai/codex ⭐ 119,566

- 🔗 https://github.com/openai/codex
- 语言：Rust
- 本周新增：9,109 stars

**项目简介**

运行在终端中的轻量编码 Agent，提供 CLI、编辑器和桌面构建形态。

**为何值得关注**

本周多次 alpha 更新集中在 subagent 和 MCP 相关能力，包括子 Agent 清理、executor hooks、中断处理、MCP 输出限制和嵌套 Agent 上下文保存。它反映了编码 Agent 正在补齐复杂任务执行能力。

---

### 4. MadsLorentzen/ai-job-search ⭐ 37,735

- 🔗 https://github.com/MadsLorentzen/ai-job-search
- 语言：Python
- 本周新增：4,828 stars

**项目简介**

运行在本机的求职自动化框架，基于 Claude Code 提供 `/setup`、`/scrape`、`/apply`、`/interview` 等流程，覆盖岗位抓取、匹配评分、简历和求职信生成、面试准备。

**为何值得关注**

它是 Agent 落地垂直场景的典型案例。项目价值不在“生成一封求职信”，而是把求职拆成可重复执行、可复查、可定制的工作流。

---

### 5. Alishahryar1/free-claude-code ⭐ 51,201

- 🔗 https://github.com/Alishahryar1/free-claude-code
- 语言：Python
- 本周新增：4,769 stars

**项目简介**

把 Claude Code、Codex、Pi、OpenCode、Cline、Aider 等多个编码 Agent 接到由 50 个提供商免费层组成的模型目录，并在失败时自动 fallback。

**为何值得关注**

多 Agent、多模型使用成本正在变成真实门槛。这个项目抓住的是“想试多个工具，但不想为每个工具单独配置一套模型和额度”的需求。

## 📈 趋势判断

### 趋势一：Prompt 和图表开始工程化

`awesome-gpt-image-2` 和 `archify` 都说明生成式内容正在被结构化、模板化、版本化。可复用比一次性生成更重要。

### 趋势二：编码 Agent 进入复杂任务执行层

`openai/codex` 的 subagent、MCP、hook 更新说明，终端 Agent 正在补齐多步骤任务所需的执行基础设施。

### 趋势三：垂直场景 Agent 开始出现真实工作流

`ai-job-search` 不是单点工具，而是完整求职流程。Agent 的商业价值通常会先在这种高重复、高文本量、高个人化场景里出现。
