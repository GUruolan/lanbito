### 1. tt-a1i/archify

**项目简介**：将 Agent 生成的结构化中间数据编译为架构、工作流、时序、数据流与生命周期图，输出自包含 HTML。

**关注价值**：适合研究“模型组织结构，渲染器确定性输出”的分工；生成图仍需对照源码核验。

### 2. bilawalsidhu/gods-eye-view

**项目简介**：浏览器中的三维空间情报界面，将公开的飞机、船舶、卫星、地震、交通与摄像头数据叠加到地球视图，并提供实时语音控制。

**关注价值**：适合前端地图和数据可视化学习；历史摘要指出部分交通数据为模拟，不能把所有图层都当成精确实测。

### 3. THU-MAIC/OpenMAIC

**项目简介**：从提示词或文档、音视频与网页材料生成课程、测验、交互内容和讲解的多 Agent 教学工具。

**关注价值**：关注从一次性生成到课程修改与恢复的流程；事实、答案和媒体内容仍需逐项审核。

### 4. K-Dense-AI/scientific-agent-skills

**项目简介**：面向科研 Agent 的技能集合，覆盖生物信息、化学、医学、药物发现和科学可视化等方向。

**关注价值**：适合按研究主题选择小范围技能。来源中的仓库描述与 README 技能数量存在差异，因此不引用固定总数。

### 5. debpalash/VoiceStudio

**项目简介**：以本地工作流为主的语音工作台，覆盖配音、声音克隆与设计、转写、听写和有声书。

**关注价值**：关注多种语音引擎如何共用工作流；语言目录规模不等于各语言都达到相同质量。

## 📈 趋势判断

图表、课程和语音都在走向可编辑产物。对开发者更有价值的阅读问题是：Agent 产生什么中间表示，用户如何检查并修正结果？
